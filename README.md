# Rule prompts

Conjunto de reglas para orientar el diseño y el desarrollo de productos web.

Las carpetas agrupan criterios por capa: dirección visual, frontend, backend, base de datos, tipos de proyecto y flujos de trabajo. También hay ejemplos de cómo combinar esas reglas según el caso, como una landing, un ecommerce, un sistema de reservas o un SaaS.

La idea es fijar criterios claros de identidad, estructura, seguridad e integridad de datos, y evitar resultados genéricos o plantillas repetidas.
