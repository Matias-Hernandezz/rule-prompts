# ANTI-GENERIC DESIGN SYSTEM

## Objetivo

Evitar que el resultado final parezca una plantilla generada automáticamente.

La interfaz debe tener una identidad visual clara y una composición intencional.

---

## 1. No utilizar patrones genéricos automáticamente

No asumir que una página debe tener:

Hero → Features → Cards → Testimonials → CTA → Footer

Ese patrón solamente debe utilizarse si tiene sentido para el producto.

La estructura debe derivarse de:

* objetivo comercial
* usuario
* identidad de marca
* contenido
* jerarquía de información

---

## 2. Evitar el "SaaS template look"

No utilizar automáticamente:

* grandes gradientes
* fondos abstractos generados sin propósito
* blobs
* glassmorphism
* cards flotantes repetitivas
* iconos dentro de círculos
* dashboards decorativos
* botones idénticos repetidos
* estadísticas inventadas
* testimonios ficticios

---

## 3. Diseñar alrededor de un concepto

Antes de crear una sección importante, definir qué concepto visual representa.

Ejemplos:

* editorial
* deportivo
* industrial
* minimalista
* brutalista
* premium
* tecnológico
* artesanal
* urbano

No mezclar estilos sin intención.

---

## 4. Crear jerarquía

Cada sección debe tener:

* elemento principal
* elementos secundarios
* espacio negativo
* ritmo visual

No intentar que todo llame la atención al mismo tiempo.

---

## 5. Usar elementos distintivos

Cuando existan recursos reales de la marca:

* fotografías
* logos
* ilustraciones
* texturas
* patrones
* colores
* tipografías
* iconografía

priorizarlos sobre elementos decorativos genéricos.

---

## 6. Evitar decoración sin propósito

No agregar elementos simplemente porque "se ven modernos".

Cada elemento visual debe contribuir a:

* identidad
* jerarquía
* navegación
* comprensión
* interacción

---

## 7. Composición

No limitarse a grids simétricos.

Cuando sea apropiado utilizar:

* asimetría
* superposición
* diferentes escalas
* profundidad
* espacios negativos
* recortes
* composición editorial
* elementos fuera del grid

Siempre manteniendo usabilidad.

---

## 8. Animación

Las animaciones deben tener propósito.

Usarlas para:

* revelar contenido
* indicar interacción
* establecer jerarquía
* generar continuidad
* mejorar percepción de calidad

No animar todo.

---

## 9. Regla de diferenciación

Antes de finalizar:

Preguntate:

"Si elimino el logo y los colores, ¿esta web podría pertenecer a cualquier otra empresa?"

Si la respuesta es sí, buscá una solución visual más específica.

---

## 10. Regla final

No intentar demostrar que la web fue hecha con tecnología moderna.

El objetivo es que parezca una experiencia digital diseñada específicamente para esa marca.
