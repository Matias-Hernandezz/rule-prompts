# IMPLEMENT FEATURE

## Objetivo

Implementar una funcionalidad sin afectar innecesariamente el resto del sistema.

---

## Antes de comenzar

Analizar:

* requerimiento
* arquitectura
* componentes existentes
* API
* modelos
* dependencias

---

## Plan

Determinar:

1. archivos a modificar
2. archivos a crear
3. dependencias necesarias
4. cambios de backend
5. cambios de frontend
6. cambios de database

---

## Implementación

Mantener separación entre:

* UI
* lógica
* datos
* backend

Reutilizar código existente.

---

## Validación

Contemplar:

* estado inicial
* loading
* éxito
* error
* estado vacío
* datos inválidos

---

## Testing

Cuando corresponda:

* tests unitarios
* tests de integración
* pruebas manuales

---

## Verificación

Después de implementar:

* ejecutar
* revisar errores
* verificar funcionalidad
* verificar responsive
* revisar efectos secundarios

---

## Restricción

No modificar funcionalidades no relacionadas con la tarea.
