# RESPONSIVE DESIGN

## Principio

Responsive no significa simplemente reducir tamaños.

La composición debe adaptarse al dispositivo.

---

## Desktop

Priorizar:

* composición
* jerarquía
* espacio negativo
* navegación
* contenido principal

---

## Tablet

Reevaluar:

* columnas
* tamaños
* espaciado
* navegación

---

## Mobile

Priorizar:

* contenido principal
* legibilidad
* interacción táctil
* navegación sencilla

Evaluar cambiar:

* grids → columnas
* navegación → menú
* composiciones horizontales → verticales
* elementos decorativos → simplificados

---

## Evitar

* overflow horizontal
* texto cortado
* botones demasiado pequeños
* elementos superpuestos accidentalmente
* imágenes deformadas
* modales inutilizables

---

## Verificación

Probar especialmente:

* 320px
* 375px
* 390px
* 768px
* 1024px
* desktop

No depender únicamente de breakpoints teóricos.

---

## Regla

El mobile debe sentirse diseñado, no simplemente reducido.
